# Customer Shopping Behavior Analysis
## Project Overview
An end-to-end data analytics project exploring customer shopping behavior using **Python, PostgreSQL and Power BI**. The project analyzes customer demographics, purchasing patterns, product performance, discount usage, subscription behavior, and seasonal trends, and generate insights that support data informed decision making.
## Tools & Technologies
- **Python (Pandas)**: Data cleaning and pre-processing
- **PostgreSQL (SQL)**: Data analysis and business queries
- **Power BI**: Dashboard development and visualization
## Project Workflow
1. **Data Loading and Exploration:** Imported and explored the dataset using Python.
2. **Data Cleaning:** Handled missing value, checked duplicate, standardized column names, and created new features.
3. **Database Integration:** Loaded the cleaned dataset into PostgreSQL.
4. **SQL Analysis:** Answered business questions about customer demographics, product performance, discount usage, subscription adoption and purchasing patterns.
5. **Dashboard Development:** Created an interactive Power BI dashboard to visualize key findings.
6. **Insights & Recommendations:** Identified trends and suggested business improvements.
## Business Recommendation
- Optimize inventory based on product and category performance.
- Develop strategies to improve customer retention and subscription adoption.
- Evaluate discount effectiveness using incremental sales and profit margins.
- Use customer and seasonal insights to support marketing decisions.
- Maintain reliable support for commonly used payment method.
- Investigate regional purchasing differences to identify opportunities for targeted marketing and product planning.

## Conclusion
This project demonstrates an end-to-end data analytics workflow, from data cleaning and preparation using Python to SQL-based analysis in PostgreSQL and interactive dashboard development in Power BI. The analysis uncovered key patterns in customer purchasing behavior, product performance, discount usage, subscription adoption, and seasonal trends. These findings provide a foundation for data-driven business decisions, helping identify opportunities to optimize inventory, improve customer retention, and refine marketing strategies.
